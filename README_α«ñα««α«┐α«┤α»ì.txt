AuraPulse Studio Pro - Android project (v3.9.7)
================================================
இதில் உங்கள் HTML player + Android-ன் சொந்த "now playing" service உள்ளது.
  - Lock screen / notification-ல் பாடல் பெயர், படம், Prev / Play / Next, seek
  - Screen off அல்லது வேறு app-ல் இருந்தாலும் பாடல் தொடர்ந்து ஒலிக்கும்
  - Back பொத்தான், Exit, Cast settings

APK உருவாக்கும் வழி (இலவசம், கணினி தேவையில்லை):
 1. github.com-ல் கணக்கு உருவாக்கி, புதிய repository (New) உருவாக்கவும்.
 2. இந்த zip-ஐ extract செய்து, உள்ளே உள்ள எல்லா கோப்புகளையும் (".github" folder உட்பட)
    repository-க்கு upload செய்யவும் (Add file > Upload files).
 3. மேலே "Actions" tab > "Build APK" > முடிவடையும் வரை காத்திருக்கவும் (சுமார் 4-6 நிமிடம்).
 4. முடிந்ததும் அந்த run-ஐத் திறந்து கீழே "Artifacts" > AuraPulseStudio-APK என்பதைப் பதிவிறக்கவும்.
 5. அதில் உள்ள .apk கோப்பை தொலைபேசியில் நிறுவவும்.

HTML-ஐ மாற்ற: app/src/main/assets/index.html கோப்பை மாற்றி upload செய்தால் புதிய APK உருவாகும்.
